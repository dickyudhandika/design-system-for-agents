Foundations

Colors

Nine semantic tokens. Use by intent, never by value — the name encodes what the color is for.

background#FDFCF8
Main canvas. Warm white. Never pure white.
foreground#1A1A1A
Primary text. Near-black, not pure black.
secondary#A1A1A1
Secondary gray. Mid-tone for subtle elements.
muted#F3F1EB
Subtle background. Sections, cards, hover states.
border#E5E2D9
Separating content only. Never decorative.
muted-foreground#A1A1A1
Secondary text, placeholders. Calibrated for AA.
primary#1A5EFF
Blue. CTAs and active states only.
primary-foreground#FFFFFF
Text on primary. White for AA on blue.
destructive#C73E3E
Errors and destructive actions only.

—Rules

  • primary is for CTAs and active states only. Not decoration, not large surfaces, not borders.
  • destructive is for errors and destructive actions only. Never for emphasis.
  • background is warm white, never #FFFFFF. The warmth reduces eye strain.
  • border separates content. If a border doesn't separate two distinct areas, it doesn't exist.
  • Semantic naming over appearance. color.primary, not color.blue — the name encodes intent.

—Rules

  • Minimum space between sections: 24px (xl). Never less.
  • Cards use xl padding by default. Flush variant uses 0.
  • Forms use xl gap between fields. Fields use sm gap internally.
  • Use gaps, not margins. Flex/grid gap — no margin collapse.
Foundations

Radius

All radius values are 0px. This is deliberate, not missing.

0px
xs → full, every step
50%
Only for radio indicators

—Why sharp

  • Sharp edges convey precision and confidence. Rounded softens and casualizes — architectural drawings, technical documents, precision instruments.
  • Don't mix radius values. No 4px or 8px "for variety." The consistency is the point.
  • 50% is reserved for radio indicators. Not avatars, not badges, not buttons.
  • Override framework defaults. Tailwind's rounded-md is 6px — set 0px explicitly.
Foundations

Elevation

Two shadows, functional only. If a shadow is visible, it's too heavy.

shadow.subtle

0 1px 2px rgba(0,0,0,0.04)
Cards, default elevation. Barely visible.

shadow.elevated

0 4px 8px rgba(0,0,0,0.08)
Popovers, dropdowns, modals.

border (no shadow)

1px solid color.border
Separation without elevation. Pick one signal.

—Rules

  • Shadows mean elevation, never decoration. If the element isn't above content, no shadow.
  • Max opacity 8%. Heavy shadow → reduce opacity, don't remove.
  • Border OR shadow, never both for the same purpose on one element.

Motion

Two durations, two easings. Feedback is fast, transitions are smooth.

Hover me — instant response
Opens a modal — content transition

—Tokens

TokenValueUse for
duration.fast150msButton press, toggle, hover feedback
duration.smooth300msPage transitions, modals, dropdowns
ease.outcubic-bezier(0.16,1,0.3,1)Default. Natural deceleration.
ease.in-outcubic-bezier(0.65,0,0.35,1)Symmetric: open/close, expand/collapse
  • Never animate layout properties (width, height, padding) — transform and opacity only.
  • Feedback is fast (150ms), transitions are smooth (300ms). Don't swap them.

Components · 10

Tabs

One convention: underline. The indicator slides — transform only.

One H1 per page, one primary per section. The overview holds the project's identity: what it is, who it's for, and the single action that matters most.
Events stream newest-first. Destructive actions in the feed confirm via modal — never inline.
Settings use section-based forms with fieldsets. Changes save on explicit submit — no autosave surprises.

Arrow keys move between tabs. The blue indicator slides with 300ms ease-out.

—Specs

TokenValue
triggerpadding 8px 12px · label-md · 500
indicator2px bar · color.primary
listbottom border 1px solid color.border
inactive textcolor.muted-foreground
  • No pill/boxed variants. Underline is the convention — pills are decorative variety.
  • Keyboard: arrows, Home, End. Every trigger is tabbable.
