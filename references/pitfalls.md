# Pitfalls

- **Dual-maintenance token drift.** Where a project has both a typed token
  registry (for docs/explorers) and Tailwind v4 `@theme`, never edit both by
  hand. The registry (or DTCG JSON) is the source; CSS is generated on
  `predev`/`prebuild`.
- **AGENTS.md drift.** After migrations, prose goes stale while tokens update.
  Discrepancy-check before importing; token files win.
- **Patch edits can swallow adjacent lines.** When fixing stale values, include
  surrounding context in both old and new strings.
- **Non-destructive means non-destructive.** Never overwrite AGENTS.md,
  tokens.css, globals.css, tailwind.config.js, or a hand-written DESIGN.md
  (`resolve.py` refuses unless the file carries its "Generated by ds4a resolve"
  marker).
- **Core stays tone-free.** A raw hex or px in `library/core.md` is a bug: it
  should be a token reference or `{{placeholder}}`. Quick check:
  `grep -nE '#[0-9A-Fa-f]{6}|[0-9]+px' library/core.md` (only the 4px-grid rule,
  fixed indicator sizes and a11y values are expected).
- **A core contract needs tokens in every tone.** Adding `components.checkbox.*`
  placeholders to core without adding those keys to each tone makes
  `resolve.py` fail with "unresolved placeholders". Add the keys to every tone,
  then run `resolve.py --tone <t> --check` for each.
- **Version fields live in the layer that changed.** Bump `version` in the core,
  tone, or overlay file that received a merge. No `library-v2.md` copies.
- **No auto-triggering.** The developer types `/ds4a ...`. Don't suggest `review`
  unprompted; never merge a suggestion that wasn't approved individually.
- **Taste lock.** Review must read the active tone's Overview and Do's/Don'ts.
  A suggestion that contradicts the tone (rounded corners on a sharp tone) is
  discarded silently.
- **Evidence gating.** No `file:line`, no suggestion.
- **Matrix is a guide, not a law.** A landing page with a signup form needs
  Input + Field + Button. When unsure, include.
- **Re-detect from files each session.** State lives in `.ds4a/project.md`,
  `DESIGN.md` and `.ds4a/pending.md`. Nothing in memory.
